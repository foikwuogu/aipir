# AIPIR training package

A one-day, hands-on workshop for up to 30 engineers and reliability managers per cohort. It
satisfies the SOW's training deliverable: curriculum, slide deck, and a script for the recorded
session. Everything runs on a laptop with the repository; no site data is needed.

| File | Purpose |
|---|---|
| `CURRICULUM.md` | Learning outcomes, agenda, module-to-lab map, prerequisites |
| `AIPIR_training_deck.pptx` | Slide deck (also used for the recorded session) |
| `INSTRUCTOR_GUIDE.md` | Preparation checklist, timing, facilitation notes, recording script |
| `labs/LAB1.md` ... `LAB6.md` | Hands-on labs (Observe, Predict, Zero-Trust, OpenTelemetry, Recover, IaC/drift/KPIs) |
| `lab_env.sh` | Sets up a lab secret and one token per training persona |
| `make_practice_records.py` | Writes SYNTHETIC practice incident records for Lab 6 (never pilot data) |
| `QUIZ.md`, `QUIZ_ANSWERS.md` | 15-question knowledge check (pass mark 80%) and answer key |
| `EVALUATION_FORM.md` | Participant feedback and attendance record |

Certificates are issued by the training partner named in the SOW. The attendance record in
`EVALUATION_FORM.md` is the evidence they need.
